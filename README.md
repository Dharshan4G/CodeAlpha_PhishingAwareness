# CodeAlpha — Task 2: Phishing Awareness Training

An interactive, self-paced online training module that teaches people to recognise and avoid phishing attacks.

**Live demo:** `https://<your-username>.github.io/CodeAlpha_PhishingAwareness/`

## Modules
1. **What is phishing:** definition and 8 attack types (spear phishing, whaling, smishing, vishing, BEC, clone phishing, quishing)
2. **Find the red flags (interactive):** a realistic fake PayPal email with 7 hidden warning signs to click and discover
3. **Spot the fake website (interactive):** 7 URLs to judge as real or fake, teaching how to read a domain, typosquatting and subdomain tricks
4. **Social engineering tactics:** urgency, authority, fear, greed, curiosity, trust, pretexting, baiting and tailgating
5. **Real-world cases:** Google/Facebook $100M invoice fraud, the 2016 Podesta email hack, the 2020 Twitter hack, and the 2023 MGM Resorts attack
6. **Best practices:** 11 protective habits plus an "already clicked?" incident response checklist
7. **Final quiz:** 10 scenario-based questions with instant feedback, a score and a pass mark of 8/10

## Tech
A single self-contained `index.html` file with HTML, CSS and vanilla JavaScript. No build step and no dependencies.
It is responsive on mobile, supports dark mode, works with the keyboard and respects reduced-motion settings.

## Run it
- **Locally:** double-click `index.html`
- **Online (GitHub Pages):** in the repo, go to Settings → Pages → Source: *Deploy from a branch* → Branch `main`, folder `/root` → Save. The site will be live in about a minute.
